## Нормативи (команда з 5 осіб) і виконання

| Норматив | Вимога | Є |
| :--- | :-: | :-: |
| Прийнятих дефектів SRS із 24 закладених | ≥ 20 | 28 (24 + 4 спірні прийнято після обговорення) |
| Дефектів на кожен із 6 критеріїв | ≥ 2 | 5 / 6 / 6 / 3 / 4 / 4 |
| Рівнів тестування у плані | усі 7 | 7 |
| Застосовних типів тестування | ≥ 15 | 16 |

Розподіл прийнятих дефектів за критеріями (однозначність / повнота / несуперечливість / простежуваність / здійсненність / тестопридатність): 5 / 6 / 6 / 3 / 4 / 4.

## Як відкривати файли

Файли `.xlsx` відкриваються в Excel або Google Sheets; `.md` — у будь-якому текстовому редакторі або на GitHub. Формули аркуша «Підсумок» перераховуються автоматично.

## Примітки до змісту

- Колонка «Хто знайшов» у реєстрі заповнена за індивідуальними аркушами незалежного аудиту кожного члена команди (двоє незалежних перевіряючих на кожен розділ SRS — див. аркуш «Розподіл розділів»).
- Правки, позначені в журналі змін SRS 1.1 колонкою «Рішення замовника», пропонує команда; вони мають бути підтверджені замовником на демо.
- Спірні рядки реєстру (№ 2, 3, 8, 11, 13, 18, 23) обговорено з Аудитором-опонентом за аркушем «Спірні»: № 2, 3, 8, 13 — прийнято після обговорення; № 11 (F-115), 18 (GUI-70), 23 (BL-20) — відхилено. Відхилені рядки з реєстру не видаляються.
- Реєстр затверджений Аудитором-опонентом (позначка в аркуші «Підсумок»).
