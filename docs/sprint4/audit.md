## Об’єкт перевірки

Поточний інкремент main: Maven-проєкт у docs/sprint4/qa-staynow, SRS 1.1, матриця покриття, UI-сценарії, записи Selenium IDE, протокол запусків, історія шести PR та шість звітів у GitHub Issues.

Джерело результатів запусків — [Surefire-протокол](qa-staynow/docs/surefire-summary.md) від 09.11.2026: виконавець Гатченко Ярослав, Windows 11, Java 17.0.21, Maven 3.9.16, Chrome 157.0.8103.38. Незалежне відтворення виконав Сімутін Владислав зі свіжої копії main за README. Юніт-набір відтворив 155 запусків, 21 failure, 1 error і 0 skipped; UI-набір двічі пройшов 9 тестів без невдач. Результати збігаються з основним протоколом.

Усі учасники перевірили свої робочі місця та відтворили підсумкові результати набору. Перевірено код, структуру, інструкцію запуску та зв’язки вимога → тест → дефект.
