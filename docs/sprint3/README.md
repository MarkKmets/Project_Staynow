## Покриття та блокування

Coverage містить зв’язки вимога → кейси і причини непокриття. Кейси F-50/F-60/GUI-40/GUI-50/GUI-80 написані, але виконання не завершене через відсутні власні тестові дані та BUG-010 (перехід до Reservation). Наявність кейсу не означає перевірену вимогу. Навантажувальні перевірки, ін’єкції та дії з чужими даними на публічному demo не виконуються.

BUG-001/004 відхилені: тарифи £137/£149/£151/£163 — значення підготовлених тестових даних, SRS не задає їх як обов’язкові тарифи базових номерів demo.
